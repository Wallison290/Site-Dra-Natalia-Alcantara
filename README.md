# Dra. Natália Alcântara | Estética Avançada

Site institucional em [Next.js](https://nextjs.org) (App Router) para a Dra. Natália Alcântara — Estética Avançada em Petrolina-PE.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build de produção

```bash
npm run build
npm run start
```

## Estrutura

- `app/` — páginas e layout (App Router)
- `app/globals.css` — estilos globais (Tailwind CSS v4)
- `public/assets/` — imagens, logo e fonte da marca

## Deploy

Projeto pronto para deploy na [Vercel](https://vercel.com): basta importar o repositório do GitHub — o framework Next.js é detectado automaticamente, sem configuração adicional.
